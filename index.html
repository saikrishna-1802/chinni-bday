📂 How to add Satwika's real photos
Step 1: Put your photo files (e.g. photo01.jpg, photo02.jpg …) in the same folder as this HTML file.

Step 2: Open the HTML in a text editor (Notepad, VS Code, etc.) and find a slide. Replace the <div class="slide-placeholder">…</div> block with <img src="photo01.jpg" alt="Memory 2007">.

Step 3: Update the data-caption and data-year on each <div class="slide"> to match the memory — these appear as the caption overlay.

Tip: You can add as many slides as you like — just copy a <div class="slide"> block and update the content. The dots and thumbnails will update automatically! 🎉
